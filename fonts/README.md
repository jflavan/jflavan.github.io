# Fonts

`satoshi-300.woff2`, `satoshi-500.woff2`, `satoshi-700.woff2` and
`satoshi-900.woff2` are the Light, Medium, Bold and Black weights of Satoshi by Deni Anggara for Indian Type
Foundry, obtained from Fontshare and self-hosted here so the site does not
depend on a third-party font host.

Satoshi is distributed under the ITF Free Font License, which permits use on
personal and commercial websites (self-hosted) but not resale or
redistribution as a font product:
https://www.fontshare.com/fonts/satoshi · https://www.fontshare.com/licenses/itf-ffl

The nav logotype mixes two more voices, both subset to the letters of the
name only (served by the Google Fonts API with a `text=` parameter):

- `instrument-serif-italic.woff2` — Instrument Serif Italic by Rodrigo
  Fuenzalida and Jordan Egstad, SIL Open Font License 1.1.
  https://fonts.google.com/specimen/Instrument+Serif
- `plex-mono.woff2` — IBM Plex Mono Medium by Mike Abbink and Bold Monday
  for IBM, SIL Open Font License 1.1. https://fonts.google.com/specimen/IBM+Plex+Mono
