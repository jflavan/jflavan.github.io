# Fonts

`satoshi-500.woff2`, `satoshi-700.woff2` and `satoshi-900.woff2` are the
Medium, Bold and Black weights of Satoshi by Deni Anggara for Indian Type
Foundry, obtained from Fontshare and self-hosted here so the site does not
depend on a third-party font host.
